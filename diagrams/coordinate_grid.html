Node Coordinates & Heuristic Distance to Goal

each node sits at an (x, y) point — h is the straight-line distance to F

A start (0,1) B (1,3) C (1,0) D (3,3) E (3,0) F goal (5,2)
h(n) = Euclidean distance from n to F(5, 2)
A(0,1): h = sqrt((5-0)² + (2-1)²) = sqrt(25 + 1) = 5.10
B(1,3): h = sqrt((5-1)² + (2-3)²) = sqrt(16 + 1) = 4.12
C(1,0): h = sqrt((5-1)² + (2-0)²) = sqrt(16 + 4) = 4.47
D(3,3): h = sqrt((5-3)² + (2-3)²) = sqrt(4 + 1) = 2.24
E(3,0): h = sqrt((5-3)² + (2-0)²) = sqrt(4 + 4) = 2.83
F(5,2): h = sqrt((5-5)² + (2-2)²) = sqrt(0 + 0) = 0.00
